# שילו שופ — אפליקציית המובייל של א.נ. שילו בע"מ

אפליקציית קניות רשמית לחנות חומרי הבניין והאספקה הטכנית **א.נ. שילו בע"מ** (קרית אתא).
האפליקציה בנויה ב-[Expo](https://expo.dev) (SDK 57) עם React Native, TypeScript ו-expo-router,
ומתחברת ישירות לחנות השופיפיי דרך ה-**Storefront API** — עיון בקטגוריות, חיפוש, דפי מוצר,
מועדפים, עגלת קניות ומעבר לתשלום מאובטח של שופיפיי. הממשק כולו בעברית, ב-RTL מלא,
ובשפה העיצובית של ת'ים "Shilo Pro" באתר (כתום `#F97316` על רקע כהה, מוטיב פס אזהרה).

## שלב 1 — יצירת טוקן Storefront API

האפליקציה מדברת עם החנות דרך ה-Storefront API של שופיפיי. לשם כך צריך טוקן גישה —
יוצרים אותו פעם אחת בממשק הניהול של החנות:

> ⚠️ **המסלול שהיה מתועד כאן סגור.** שופיפיי ביטלה את legacy custom apps ב-1
> בינואר 2026, ותפריט **Develop apps** לא קיים יותר בממשק הניהול. מי שעקב אחרי
> ההוראות האלה חיפש תפריט שאינו קיים ולא היה לו איך לדעת שהמסלול העובד מתועד
> בקובץ אחר.

המסלול הנכון הוא **ערוץ Headless**, והוא מתועד במקום אחד:
[`docs/INSTALL-APP.md` §1](../docs/INSTALL-APP.md). בקצרה — התקנת Headless
מה-App Store, יצירת custom storefront, והעתקת ה-**PUBLIC access token**.

הרשאות: תנו לטוקן רק את מה שהאפליקציה קוראת בפועל — מוצרים, קטגוריות, חיפוש,
המלצות ועגלה (`src/api/queries.ts` הוא הרשימה המלאה). ההוראות הקודמות אמרו לסמן
את **כל** ההרשאות שמתחילות ב-`unauthenticated_`, כולל קריאה וכתיבה של לקוחות
וצ'קאאוטים — הרשאות שהאפליקציה לא משתמשת בהן, על טוקן שנמצא בכל בנדל מותקן ולכן
ניתן לחילוץ.

> **הערת אבטחה:** טוקן Storefront הוא טוקן *ציבורי* — הוא מיועד לשימוש בצד לקוח
> (אפליקציה/אתר) ומאפשר קריאה בלבד ופעולות עגלה. אין להשתמש כאן בטוקן **Admin API**
> (שמתחיל ב-`shpat_`) — הוא סודי ואסור שיגיע לאפליקציה. ה-PRIVATE token של ערוץ
> ה-Headless סודי באותה מידה.

## שלב 2 — הגדרת src/config.ts

פתחו את הקובץ [`src/config.ts`](src/config.ts) ועדכנו:

```ts
export const SHOPIFY_CONFIG = {
  /** דומיין ה-myshopify של החנות (לא הדומיין המותאם!) */
  storeDomain: 'anshilo.myshopify.com',
  /** הטוקן שהעתקתם בשלב 1 */
  storefrontAccessToken: 'הדביקו-כאן-את-הטוקן',
  /** גרסת ה-API — עדכנו פעם בשנה לגרסה נתמכת */
  apiVersion: '2025-07',
} as const;
```

שימו לב:

- **`storeDomain`** — תמיד כתובת ה-`myshopify.com` המקורית של החנות, לא `anshilo.com`.
- **`storefrontAccessToken`** — הטוקן משלב 1, בלי רווחים.
- **`apiVersion`** — ראו סעיף [עדכון גרסת ה-API](#עדכון-גרסת-ה-api--פעם-בשנה).

באותו קובץ נמצא גם `STORE_INFO` — פרטי החנות שמוצגים באפליקציה (טלפון, וואטסאפ,
כתובת, שעות פתיחה). כדאי לוודא שהם מעודכנים; את מספר הוואטסאפ מזינים בפורמט
בינלאומי, למשל `972501234567`.

## שלב 3 — התקנה והרצה

מתוך תיקיית `mobile-app`:

```bash
npm install
npx expo start
```

בסיום הטעינה יופיע קוד QR בטרמינל:

- **אנדרואיד:** פתחו את אפליקציית Expo Go וסרקו את הקוד מתוכה.
- **iOS:** סרקו את הקוד עם מצלמת הטלפון ואשרו פתיחה ב-Expo Go.

בהרצה ראשונה (או אחרי שינוי הגדרות) מומלץ לנקות מטמון:

```bash
npx expo start -c
```

## בדיקה על מכשיר אמיתי

- ודאו שהטלפון והמחשב באותה רשת Wi-Fi. אם הרשת חוסמת תקשורת בין מכשירים
  (נפוץ ברשתות משרדיות), הריצו במצב מנהרה: `npx expo start --tunnel`.
- **RTL:** האפליקציה כופה כיווניות ימין-לשמאל. בפתיחה הראשונה ב-Expo Go ייתכן
  שהפריסה תופיע הפוכה — סגרו את האפליקציה לגמרי ופתחו שוב (ראו
  [פתרון תקלות](#פתרון-תקלות)). בבניית production הבעיה לא קיימת.
- מעבר לתשלום נפתח בדפדפן מאובטח בתוך האפליקציה; בסיום ההזמנה העגלה מתאפסת
  אוטומטית בחזרה לאפליקציה.

## בנייה לחנויות האפליקציות (EAS)

הבנייה נעשית בענן של Expo באמצעות **EAS Build** — לא צריך Mac וגם לא Android Studio.

### הכנה חד-פעמית

```bash
npx eas-cli login          # התחברות לחשבון Expo (יוצרים חינם ב-expo.dev)
npx eas-cli build:configure   # יוצר קובץ eas.json ומקשר את הפרויקט
```

מזהי האפליקציה כבר מוגדרים ב-`app.json`:
`com.anshilo.shop` (גם ב-iOS וגם באנדרואיד).

### בנייה

```bash
# Android — קובץ AAB לחנות Google Play
npx eas-cli build --platform android --profile production

# iOS — לחנות App Store
npx eas-cli build --platform ios --profile production
```

### חשבונות מפתח — מה צריך לדעת

| פלטפורמה | חשבון | עלות | הערות |
|---|---|---|---|
| **iOS** | [Apple Developer Program](https://developer.apple.com/programs/) | ‎99$ לשנה | חובה לפרסום ב-App Store. בזמן `eas build` תתבקשו להתחבר עם ה-Apple ID — EAS מייצר ומנהל את התעודות והפרופילים אוטומטית. |
| **אנדרואיד** | [Google Play Console](https://play.google.com/console) | ‎25$ חד-פעמי | EAS מייצר ושומר את מפתח החתימה (keystore) עבורכם — אל תאבדו גישה לחשבון ה-Expo. |

### העלאה לחנויות

אפשר להוריד את הקובץ המוכן מהקישור שמתקבל בסוף הבנייה ולהעלות ידנית,
או להשתמש ב-`eas submit`:

```bash
npx eas-cli submit --platform android
npx eas-cli submit --platform ios
```

בהעלאה הראשונה לכל חנות צריך למלא דף אפליקציה (תיאור, צילומי מסך, מדיניות
פרטיות) בממשקי App Store Connect / Play Console.

## עדכון גרסת ה-API — פעם בשנה

שופיפיי משחררת גרסת API כל רבעון, וכל גרסה נתמכת **12 חודשים** בלבד.
האפליקציה מוגדרת כרגע על `2025-07`, כלומר יש לעדכן עד יולי 2026.

1. בדקו מהי הגרסה היציבה העדכנית: <https://shopify.dev/docs/api/usage/versioning>
2. עדכנו את `apiVersion` ב-`src/config.ts`, למשל:

   ```ts
   apiVersion: '2026-07',
   ```

3. הריצו את האפליקציה ועברו על המסכים המרכזיים (בית, קטגוריה, מוצר, עגלה,
   תשלום) לוודא שהכול תקין.
4. בנו והעלו גרסה חדשה לחנויות.

> אם שוכחים לעדכן — שופיפיי מפנה בקשות מגרסה שפגה לגרסה הישנה ביותר הנתמכת,
> כך שהאפליקציה בדרך כלל תמשיך לעבוד, אבל אין להסתמך על זה.

## נכסי גרפיקה (אייקונים)

אייקון האפליקציה, האייקון האדפטיבי לאנדרואיד, סמל מסך הפתיחה וה-favicon
נוצרים על ידי סקריפט ייעודי (ללא תלות בכלי עיצוב):

```bash
npm run generate-assets
# או: node scripts/generate-assets.js
```

הסקריפט מייצר את הקבצים ב-`assets/` לפי צבעי המותג שב-`src/theme.ts`.
אם משנים את הלוגו — עורכים את `scripts/generate-assets.js` ומריצים שוב.

## עדכונים אחרי פרסום (OTA) — לא זמין כרגע, ובמכוון

`eas.json` הצהיר `channel` על כל ארבעת פרופילי הבילד, אבל `expo-updates` אינו
תלות של הפרויקט — כלומר לא היה שום רנטיים שיכול היה להוריד עדכון. השדות הוסרו,
כי קונפיג שמצהיר על יכולת שאינה קיימת גרוע מקונפיג שלא מצהיר עליה: מי שהיה
מסתמך עליו היה מניח שתיקון של מחרוזת או של `apiVersion` נדחף ב-`eas update`,
ובפועל כל תיקון דורש בילד מלא ומעבר נוסף בבדיקת החנויות.

אם רוצים OTA באמת: `npx expo install expo-updates`, להחזיר את שדות ה-`channel`,
ולקבוע `runtimeVersion` ב-`app.json` — עם `appVersionSource: "remote"` ועם
`autoIncrement`, בלי מדיניות runtimeVersion כל בילד נוחת על גרסת רנטיים חדשה
ואף בילד קיים לא יוכל לקבל את העדכון בכל מקרה.

## פתרון תקלות

### ‏"טוקן ה-Storefront API שגוי או חסר" (שגיאת 401/403)

- ודאו שהעתקתם את ה-**PUBLIC access token** של ה-custom storefront בערוץ
  Headless, ולא את ה-private token ולא טוקן Admin.
- ודאו שהמוצרים והקטגוריות **מפורסמים לערוץ Headless** — בלי זה ה-API מחזיר אפס
  מוצרים בלי שגיאה. הפירוט ב-[`docs/INSTALL-APP.md`](../docs/INSTALL-APP.md).
- בדקו שאין רווחים או תווים חסרים בטוקן שב-`src/config.ts`.
- אחרי כל שינוי ב-`config.ts` הפעילו מחדש עם ניקוי מטמון: `npx expo start -c`.

### הפריסה מופיעה משמאל לימין (RTL לא נתפס)

כפיית ה-RTL נטענת פעם אחת בעליית האפליקציה. אם המסך נראה הפוך:

1. עצרו את השרת והריצו `npx expo start -c`.
2. סגרו את Expo Go לגמרי (החלקה מרשימת האפליקציות הפתוחות) ופתחו מחדש.
3. בבניית production (EAS) הכיווניות מוגדרת ברמת המערכת ותמיד תקינה.

### "אין חיבור לאינטרנט" / שגיאות רשת

- בדקו שהמכשיר מחובר לאינטרנט ושאין VPN או חומת אש שחוסמים את
  `*.myshopify.com`.
- ודאו ש-`storeDomain` נכון — כתובת `myshopify.com`, בלי `https://` ובלי `/`.
- ברשתות שחוסמות תקשורת מקומית הריצו `npx expo start --tunnel`.

### מוצרים או קולקציות לא מופיעים

- ודאו שהמוצרים **פורסמו לערוץ המכירה** של האפליקציה שיצרתם (בדף המוצר
  בשופיפיי: Publishing / Sales channels).
- מוצרים בסטטוס Draft לא יופיעו — רק Active.

### תקלות כלליות / התנהגות מוזרה אחרי עדכון

```bash
npx expo start -c            # ניקוי מטמון Metro
rm -rf node_modules && npm install   # התקנה נקייה במקרה הצורך
npx tsc --noEmit             # בדיקת שגיאות TypeScript
```

## מבנה הפרויקט

```
mobile-app/
├── app/                  # מסכים (expo-router — ניתוב לפי קבצים)
├── assets/               # אייקונים ומסך פתיחה (נוצרים בסקריפט)

│   ├── api/              # לקוח Storefront API, שאילתות וטיפוסים
│   ├── components/       # רכיבי UI משותפים
│   └── state/            # עגלה ומועדפים (Context + AsyncStorage)
├── app.json              # הגדרות Expo (שם, אייקונים, RTL, splash)
└── package.json
```
