# התקנת הת'ים ופרסומו

מדריך לבעל החנות. אין צורך בידע בתכנות.

---

## 1. הת'ים כבר מותקן

העיצוב החדש הועלה לחנות כת'ים **לא מפורסם**, כלומר הוא קיים בחנות אבל אף לקוח
לא רואה אותו. שם הת'ים:

> **שילו 2026 — העיצוב החדש ⭐**

**לצפייה:** https://anshilo.com/?preview_theme_id=148368425039

או מתוך הניהול: **חנות מקוונת → ערכות נושא** → מוצאים את הת'ים בקטע
"ערכות נושא של הספרייה" → **תצוגה מקדימה**.

האתר החי (`שמירה 1`) לא נגעו בו והוא ממשיך לעבוד רגיל.

יש גם ת'ים בשם **`למחיקה — ייבוא כושל (בלי צבעים)`** — זו טיוטה מניסיון העלאה
שנכשל. אפשר למחוק אותה בשקט: שלוש הנקודות שליד הת'ים → **מחיקה**.

## 3. פרסום

**חנות מקוונת → ערכות נושא** → שלוש הנקודות שליד `שילו 2026 — העיצוב החדש ⭐` →
**פרסום**. זה מיידי, וגם הפיך: אם משהו לא מסתדר, אפשר לפרסם חזרה את `שמירה 1`
באותה דרך.

> **לפני הפרסום**: הת'ים החדש הוא ת'ים אחר, ולכן **אפליקציות שהיו מוטמעות
> בת'ים הישן לא יופיעו בו אוטומטית**. אפליקציית הנגישות (sense-rtl) כן חוברה
> מראש. אם יש אפליקציות נוספות שחשובות לכם (תגיות מוצר, ניוזלטר, ביקורות) —
> אחרי הפרסום צריך להיכנס לכל אפליקציה כזו ולהפעיל אותה מחדש על הת'ים החדש.

## 4. עריכת האתר בלי קוד

**חנות מקוונת → ערכות נושא → התאמה אישית** על הת'ים החדש.

### הגדרות כלליות (אייקון גלגל השיניים בתחתית התפריט הימני)

| קטגוריה | מה יש שם |
|---|---|
| **מיתוג** | לוגו, רוחב הלוגו, אייקון האתר |
| **צבעים** | צבע המותג, הכהה הראשי, רקעים, טקסט, קווים, מצבי מלאי |
| **טיפוגרפיה** | גודל כותרות וגוף הטקסט |
| **פריסה וסגנון** | רוחב התוכן, עיגול פינות, אנימציות |
| **כרטיסי מוצר** | יחס תמונה, הצגת מותג/מלאי/מקט, תגיות מבצע, מוצרים בעמוד |
| **עגלה וחיפוש** | סוג העגלה, סכום למשלוח חינם, חיפושים פופולריים |
| **פרטי החנות** | טלפון, וואטסאפ, אימייל, כתובת, שעות, רשתות חברתיות |

**שווה לדעת:** הפרטים שבקטגוריה "פרטי החנות" מוזרמים אוטומטית להדר, לפוטר,
לעמוד צור קשר, לכפתורים הצפים ולנתונים שגוגל קורא. שינוי במקום אחד מתעדכן בכל
האתר.

> **אזהרה אחת:** בקטגוריית טיפוגרפיה יש אפשרות "שימוש בגופני שופיפיי". **אל
> תסמנו אותה.** ספריית הגופנים של שופיפיי לא כוללת אותיות עבריות, וסימון
> האפשרות יגרום לכל העברית באתר להיראות בגופן ברירת המחדל של המחשב.

### החלפת הלוגו

הלוגו הנוכחי מוערם — האייקון מעל הכתובית — ולכן בהדר הוא מוצג בגובה מוגבל
(54 פיקסלים בטלפון, 68 במחשב) והכתובית יוצאת קטנה. **אם יש גרסה אופקית של
הלוגו** (האייקון ליד הטקסט ולא מעליו) היא תיראה משמעותית טוב יותר. להחלפה:
הגדרות → מיתוג → לוגו.

### שינוי המחלקות בדף הבית

בעורך, בוחרים את הסקשן **"רשימת קטגוריות"** או **"המחלקות שלנו"**. כל אריח הוא
בלוק — אפשר לגרור לשינוי סדר, ללחוץ על אריח כדי להחליף קטגוריה, להעלות תמונה
מותאמת, או ללחוץ על העין כדי להסתיר.

### תמונת הירו

הירו כרגע מוצג על רקע כחול־כהה מעוצב עם רשת שרטוט — הוא נראה טוב גם בלי תמונה.
להוספת צילום: בעורך בוחרים את **"באנר תמונה"** → **תמונת רקע**. מומלץ 2400×1200
לפחות, ותמונה נפרדת לטלפון. אם התמונה כהה, מקטינים את "כהות שכבת ההצללה".

### עמוד ההזמנה המהירה

הסקשן קיים בתבנית `page.quick-order`. כדי שהעמוד יעבוד צריך **עמוד** בחנות עם
הכתובת `quick-order`: **חנות מקוונת → עמודים → הוספת עמוד**, שם "הזמנה מהירה
לפי מקט", ובקטע "ערכת נושא" בוחרים את התבנית **quick-order**. אותו דבר לעמוד
השאלות הנפוצות — תבנית **faq**.

## 5. עדכון הת'ים מהקוד

הת'ים נמצא בתיקיית `theme/` בריפוזיטורי. יש שתי דרכים להעלות שינויים:

### א. חיבור ל-GitHub (מומלץ)

**חנות מקוונת → ערכות נושא → הוספת ערכת נושא → התחברות מ-GitHub**, בוחרים את
הריפוזיטורי ואת הענף. מאותו רגע כל שינוי בקוד מסתנכרן לת'ים אוטומטית. זו הדרך
הנוחה ביותר לתחזוקה שוטפת.

### ב. העלאת קובץ ZIP

```bash
cd theme && zip -r ../shilo-pro-theme.zip . -x "tools/*" "SPEC.md" "DESIGN-SYSTEM.md"
```

ואז **חנות מקוונת → ערכות נושא → הוספת ערכת נושא → העלאת קובץ ZIP**.

> **שתי מלכודות בייבוא ZIP** ששווה להכיר, כי שופיפיי לא מדווח עליהן — הוא פשוט
> משתיק את הקובץ:
> 1. אם ל-`config/settings_schema.json` יש הגדרה עם `"default": ""` ריק, שופיפיי
>    **דוחה את כל הקובץ** ומחליף אותו ב-`[]`. התוצאה: אתר בלי צבעים ובלי גופנים.
> 2. סוגר מסולסל בתוך תג Liquid (למשל `{{ x | append: '{y}' }}`) גורם לדחיית
>    הקובץ כולו.
>
> `python3 theme/tools/validate.py` מזהה את שתי המלכודות לפני העלאה. כדאי להריץ
> אותו תמיד.
