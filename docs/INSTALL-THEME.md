# 🎨 התקנת ערכת העיצוב "Shilo Pro" בשופיפיי

מדריך צעד-צעד להעלאת הת'ים החדש לחנות — בלי צורך בידע טכני.

> ⏱️ זמן משוער: 15–30 דקות (כולל התאמות תוכן)

## שלב 1: יצירת קובץ ה-ZIP

במחשב עם התיקייה הזו (או ב-GitHub — Code → Download ZIP ואז לחלץ):

**ב-Windows:** נכנסים לתיקיית `theme`, מסמנים את **כל** התיקיות שבתוכה (assets, config, layout, locales, sections, snippets, templates), קליק ימני → *Compress to ZIP file*.

**במק/לינוקס (טרמינל):**

```bash
cd theme
zip -r ../shilo-pro-theme.zip assets config layout locales sections snippets templates
```

> ⚠️ חשוב: ה-ZIP צריך להכיל את התיקיות עצמן (assets, config...) ולא תיקיית `theme` עוטפת.

## שלב 2: העלאה לשופיפיי

1. נכנסים לניהול החנות: `https://admin.shopify.com`
2. **Online Store → Themes** (חנות מקוונת → ערכות עיצוב)
3. גוללים ל-**Theme library** ולוחצים **Add theme → Upload zip file**
4. בוחרים את `shilo-pro-theme.zip` שיצרנו

הת'ים יופיע בספרייה תוך דקה. **עדיין לא לוחצים Publish!**

## שלב 3: התאמה אישית לפני פרסום

לוחצים **Customize** על הת'ים החדש ועוברים על הדברים האלה:

### חובה לבדוק

- **לוגו** — Theme settings → לוגו ומיתוג → מעלים את הלוגו של החנות
- **תפריט ראשי** — הת'ים משתמש בתפריט `main-menu` הקיים. אם הקטגוריות לא מופיעות: **Online Store → Navigation** ומוודאים שהתפריט הראשי מכיל את הקטגוריות (עץ, טמבור, נירלט, חוליות...)
- **דף הבית** — לכל סקשן (באנר ראשי, קטגוריות, מוצרים מומלצים) בוחרים תמונות וקטגוריות אמיתיות מהחנות
- **פרטי החנות** — Theme settings → פרטי החנות: טלפון, וואטסאפ, כתובת, שעות פעילות
- **רשתות חברתיות** — Theme settings → רשתות חברתיות

### כדאי לבדוק

- **משלוח חינם** — Theme settings → עגלת קניות → סכום למשלוח חינם (מציג פס התקדמות מעודד בעגלה). להשאיר ריק אם אין משלוח חינם.
- **חיפושים פופולריים** — Theme settings → חיפוש: המילים שמוצגות כשפותחים את החיפוש
- **צבעים וגופנים** — ברירת המחדל מעוצבת בקפידה, אבל הכל ניתן לשינוי ב-Theme settings

## שלב 4: תצוגה מקדימה ופרסום

1. בעורך לוחצים על אייקון העין 👁 לתצוגה מקדימה — עוברים על: דף הבית, עמוד קטגוריה, עמוד מוצר, הוספה לעגלה, חיפוש, יצירת קשר — **גם בטלפון!** (בתחתית העורך יש מתג תצוגת מובייל)
2. כשהכל נראה טוב: חוזרים ל-**Themes**, ליד הת'ים החדש לוחצים **⋯ → Publish**
3. הת'ים הקודם נשמר אוטומטית בספרייה — אפשר לחזור אליו בכל רגע (Publish על הישן)

## שאלות נפוצות

**מה קורה למוצרים ולהזמנות?** כלום. ת'ים משנה רק את העיצוב — מוצרים, מלאי, הזמנות ולקוחות לא מושפעים.

**עמוד יצירת הקשר לא מעוצב?** צריך לשייך לו את התבנית: **Online Store → Pages → צור קשר**, ובצד ימין תחת *Theme template* לבחור **contact**.

**החנות באנגלית פתאום?** בודקים ב-**Settings → Languages** שהשפה הראשית היא עברית (Hebrew).

**איך עורכים את הבלוג?** הת'ים כולל עיצוב מלא לבלוג — כתבות חדשות ב-**Online Store → Blog posts** יקבלו אוטומטית את העיצוב.

**משהו נשבר?** תמיד אפשר לפרסם חזרה את הת'ים הישן מהספרייה. הקוד המלא כאן ב-repo, אז כל שינוי אפשר לשחזר.
