# הפעלת אפליקציית המובייל

האפליקציה בנויה ב-Expo (React Native) ומושכת את המוצרים, הקטגוריות, המלאי
והמחירים ישירות מהחנות דרך Shopify Storefront API. אין בסיס נתונים נפרד ואין
מה לתחזק - כל שינוי בחנות מופיע באפליקציה מיד.

התשלום מתבצע ב-Checkout של שופיפיי עצמו, כך שכל אמצעי התשלום שמוגדרים בחנות
עובדים גם באפליקציה.

---

## שלב 1 - יצירת טוקן Storefront API

> **תוקן.** הגרסה הקודמת של המסמך הזה הפנתה ל**הגדרות → אפליקציות וערוצי מכירה →
> פיתוח אפליקציות**, ומשם ללשונית **API credentials** שהציגה את הטוקן.
> **המסלול הזה לא קיים יותר.** התיעוד של שופיפיי קובע: *"You can no longer create
> new custom apps in the Shopify admin"*, ו*"as of January 1, 2026, you can no
> longer create new legacy custom apps"*. אפליקציות שנוצרו כך בעבר ממשיכות לעבוד,
> אבל אי אפשר ליצור חדשות.
>
> אפליקציה שנוצרת ב-**Dev Dashboard** גם היא לא פותרת את זה: היא לא מציגה את
> הטוקן בשום מסך בממשק הניהול, כי שופיפיי מצפה שהאפליקציה תשלוף אותו בעצמה
> ב-OAuth או במוטציה `storefrontAccessTokenCreate` מול ה-Admin API.

**המסלול הנכון היום: ערוץ Headless.** שופיפיי כותבת במפורש שערוץ זה **מייצר את
הטוקנים בשבילכם ומציג אותם בממשק** - בלי קוד, בלי CLI, בלי לגעת ב-API secret.

1. **הגדרות → אפליקציות וערוצי מכירה → Shopify App Store** → להתקין את
   **Headless**
2. ליצור **custom storefront** חדש
3. במסך הטוקנים יופיעו **שני** טוקנים. לקחת את זה שמסומן
   **Public access token**

### ⚠️ שני דברים שחייבים לקרות אחרי ההתקנה

**1. לפרסם את הקטלוג לערוץ החדש.** ערוץ Headless יוצר **publication** חדשה.
נבדק מול החנות: **לכל חמש ה-publications הקיימות `autoPublish: false`**, כלומר
מוצרים **לא** מתפרסמים אוטומטית לערוץ חדש. בלי השלב הזה ה-API יחזיר 200 עם **אפס
מוצרים**, וזה נראה בדיוק כמו טוקן שגוי.

> מוצרים → לסמן הכל → **פעולות בכמות** → הוספת ערוץ מכירה → Headless.
> לחזור על אותו דבר לקטגוריות.

**2. לא לבלבל בין שני הטוקנים.**

| טוקן | סודי? | לאפליקציה? |
|---|---|---|
| **Public access token** | לא. ציבורי בהגדרתו, נועד לצד לקוח | ✅ **זה מה שנכנס ל-config** |
| **Private access token** | **כן. סודי** | ❌ אסור בבנדל של האפליקציה |

ה-Private token מיועד לשרת בלבד. הוא יושב על אותו מסך בדיוק, ולכן קל להעתיק את
הלא-נכון. **האפליקציה היא צד לקוח - היא תמיד מקבלת את ה-Public.**

## שלב 2 - הדבקת הטוקן

פותחים את `mobile-app/src/config.ts` ומדביקים:

```ts
storefrontAccessToken: 'המקום-שבו-מדביקים-את-הטוקן',
```

הדומיין כבר מוגדר נכון:

```ts
storeDomain: '3007b3-4.myshopify.com',
```

זה הדומיין הפנימי של החנות בשופיפיי - **לא** `anshilo.com`. אין צורך לשנות אותו.

שאר הפרטים בקובץ (טלפון, וואטסאפ, כתובת, שעות) כבר מלאים בערכים האמיתיים, ומשם
הם מוזרמים לכל המסכים.

## שלב 3 - הרצה על הטלפון

```bash
cd mobile-app
npm install
npx expo start
```

מתקינים **Expo Go** מה-App Store או מ-Google Play, סורקים את ה-QR שמופיע
בטרמינל, והאפליקציה נפתחת על הטלפון. כל שינוי בקוד מתעדכן במסך תוך שנייה.

לבדיקה שהכל מתקמפל:

```bash
npx tsc --noEmit
```

## מה יש באפליקציה

| מסך | מה בו |
|---|---|
| בית | חיפוש, רצועת מחלקות, מבצעים, נמכרים ביותר, חדש בקטלוג, מותגים |
| קטלוג | כל הקטגוריות עם מיון וטעינה אינסופית |
| קטגוריה | רשת מוצרים, מיון, טעינה בגלילה |
| מוצר | גלריה, בחירת וריאנט, מלאי, מחיר, הוספה לעגלה, שיתוף |
| חיפוש | חיפוש מוצרים מהיר |
| עגלה | מסונכרנת עם שופיפיי, נשמרת בין הפעלות, מעבר ל-Checkout |
| מועדפים | נשמרים על המכשיר |
| עוד | פרטי החנות, טלפון ווואטסאפ בלחיצה, שעות פעילות, מדיניות |

העיצוב זהה למערכת העיצוב של האתר - אותו אדום, אותו כחול-כהה, אותם כרטיסים -
כדי שהאתר והאפליקציה ירגישו כמו מוצר אחד.

## שלב 4 - העלאה ל-App Store ול-Google Play

זה שלב נפרד שדורש חשבונות מפתח בתשלום. מה שצריך:

| דרישה | עלות | הערות |
|---|---|---|
| Apple Developer Program | 99$ לשנה | חובה ל-iOS |
| Google Play Developer | 25$ חד-פעמי | חובה לאנדרואיד |
| חשבון Expo (EAS) | חינם להתחלה | לבניית הקבצים בענן. `eas.json` כבר מוגדר עם שלושה פרופילים: development, preview, production |
| אייקון אפליקציה | - | 1024×1024, ללא שקיפות |
| מסכי צילום | - | לפי מידות החנויות |
| מדיניות פרטיות | - | חובה בשתי החנויות; אפשר להפנות לעמוד באתר |

התהליך עצמו:

```bash
npm install -g eas-cli
eas login
# eas.json כבר קיים בריפוזיטורי - אין צורך ב-build:configure
eas build --platform ios --profile production        # בונה בענן
eas build --platform android --profile production
eas submit --platform ios --profile production       # שולח לבדיקה
eas submit --platform android --profile production
```

הבדיקה באפל לוקחת בדרך כלל 1-3 ימים, בגוגל בין כמה שעות ליום.

> **טיפ:** אפל דוחה לפעמים אפליקציות חנות שהן "רק אתר בתוך מסגרת". האפליקציה
> הזאת אינה כזו - היא native ומשתמשת ב-API - אבל שווה להדגיש בתיאור את מה
> שייחודי לה: המועדפים, הזמנה מהירה לפי מקט, וההתקשרות והוואטסאפ בלחיצה.
