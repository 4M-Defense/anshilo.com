# מה נשאר לתקן ב-Merchant Center, ומה בדיוק להדביק

נכתב אחרי סבב שסגר ארבעה פריטים. כל מה שכאן דורש הרשאות שאין לטוקן ה-API
של החנות — הוא מחזיק `write_products` ו-`write_files` בלבד, ולא `write_themes`,
`write_legal_policies` או גישה לעמודים. לכן זה כתוב להדבקה ידנית או לסוכן דפדפן.

**מה שכבר נסגר ולא צריך טיפול:** כותרות SEO (2,714 → 0), קטגוריות חסרות
(514 → 0), קטגוריות שגוגל חוסמת (36 → 0), התמונה עם הכיתוב הפרסומי,
ו-52 תמונות שהוגדלו לפיקסלים אמיתיים (455 → 403 מתחת ל-500).

## 1. שלושה סעיפים חסרים במדיניות ההחזרים

המדיניות ב-`/policies/refund-policy` **כבר תואמת ברוב הדין** — היא כוללת את
תקרת ה-100 ₪, את שעות המענה, את "לפי המאוחר", את ארבעת החודשים לאזרח ותיק
ולעולה חדש, ואת הפטור מדמי ביטול בפגם. חסרים שלושה דברים.

**להוסיף בסוף הפסקה "מועד ואופן ההחזר הכספי":**

> בעסקה שנעשתה בחנות, ההחזר יינתן במועד הביטול ולא יאוחר משבעה ימי עסקים
> ממועד מסירת הודעת הביטול.

**להוסיף לרשימת "מוצרים שלא ניתן לבטל את רכישתם":**

> מידע דיגיטלי, לרבות תוכנה, קוד הפעלה או מוצר שהורד או הופעל.
>
> מוצר הניתן להקלטה, לשעתוק או לשכפול, שאריזתו המקורית נפתחה.

**להוסיף כפסקה חדשה בסוף המסמך, לפני "שאלות":**

> ### איך נספרים הימים
>
> תקופת הביטול נמנית מהיום שלמחרת המועד הקובע, וכוללת ימי מנוחה, שבתות
> וחגים. אם היום האחרון של התקופה הוא יום מנוחה, שבת או חג, התקופה מסתיימת
> ביום העסקים שאחריו.

## 2. קישור להודעת ביטול בדף הבית

החוק דורש שבעסקאות שנעשות דרך האתר יהיה **קישור ייעודי בדף הבית** לשליחת
הודעת ביטול. נמדד: בדף הבית יש קישורים למדיניות ההחזרים, לתקנון, לפרטיות
ולצור קשר — **ואין קישור ייעודי להודעת ביטול.**

בכותרת התחתונה, ליד "מדיניות החזרים וביטולים", להוסיף:

```
טקסט הקישור:  הודעה על ביטול עסקה
יעד:          /pages/contact?subject=cancellation
```

**על הפער בין החלטת העסק לחוק.** ההחלטה היא שביטול נעשה בשיחת טלפון בלבד,
ואין רצון בטופס ביטול עצמי. החוק מאפשר הודעת ביטול **בעל פה או בכתב**, ולכן
ניסוח שקובע טלפון כערוץ יחיד אינו תואם. מה שכן עומד בשניהם: הקישור מוביל
לעמוד צור קשר הקיים, שם יש טלפון, וואטסאפ וטופס. אין כאן זרימת ביטול
אוטומטית — הצוות מטפל בכל הודעה — אבל גם אין סירוב לקבל הודעה בכתב.

בעמוד צור קשר להוסיף שורה אחת:

> ניתן להודיע על ביטול עסקה בטלפון 02-534-3422 בימים א׳-ה׳ בין 07:00 ל-17:00
> וביום ו׳ בין 07:00 ל-14:00, או בכתב במייל info@anshilo.com, בוואטסאפ, או
> בטופס שבעמוד זה.

## 3. דמי ביטול — ההגדרה ב-Shopify גובה יותר מהמותר

`Settings → Policies → Default rules → Return rules`:
`Charge restocking fee` מסומן על **5% ללא שדה תקרה**, ול-Shopify אין שדה כזה.

החוק: 5% או 100 ₪, **לפי הנמוך**. 5% מגיעים ל-100 ₪ בהזמנה של 2,000 ₪, ולכן
בכל הזמנה מעל 2,000 ₪ ההגדרה הנוכחית גובה יותר מהמותר.

**המדיניות הכתובה נכונה** ואומרת "לפי הסכום הנמוך מביניהם". הבעיה היא רק
בזרימה האוטומטית של Shopify, שאינה קוראת את המדיניות.

שתי דרכים, ואחת מהן צריכה להיבחר:

- **לכבות `Charge restocking fee`** ולגבות ידנית לפי המדיניות. בטוח לחלוטין,
  ודורש שהצוות יזכור.
- **להשאיר 5%** ולתקן ידנית כל החזרה מעל 2,000 ₪. חוסך עבודה ברוב המקרים
  ומשאיר חשיפה במקרים הגדולים.

ההמלצה היא לכבות, כי הסנקציה היא 25,350 ₪ לתאגיד והחזרה של 3,000 ₪ תגבה
150 ₪ במקום 100 ₪.

## 4. Google Customer Reviews — שני קטעי קוד שחסרים

ההסכם נחתום ומאושר, אבל MC מדווח שלא נאספו נתונים. הסיבה: שני קטעי הקוד
אינם באתר. אין שדה `Additional scripts` כי החנות עברה ל-Checkout Extensibility,
ולכן זה נעשה דרך **Customer events**.

`Settings → Customer events → Add custom pixel`, בשם `Google Customer Reviews`,
עם הקוד הזה. `merchant_id` הוא 5328155131.

```js
// Google Customer Reviews — opt-in ל-survey אחרי הזמנה.
// רץ כפיקסל של Customer events, כי אין Additional scripts ב-Checkout Extensibility.
analytics.subscribe('checkout_completed', (event) => {
  const c = event.data.checkout;
  if (!c) return;

  // תאריך אספקה משוער. GCR דורש שדה הזה, וחלון של 7 ימים סביר לחנות הזאת.
  const est = new Date();
  est.setDate(est.getDate() + 7);
  const deliveryDate = est.toISOString().slice(0, 10);

  const s = document.createElement('script');
  s.src = 'https://apis.google.com/js/platform.js?onload=renderOptIn';
  s.async = true;

  window.renderOptIn = function () {
    window.gapi.load('surveyoptin', function () {
      window.gapi.surveyoptin.render({
        merchant_id: 5328155131,
        order_id: String(c.order?.id ?? c.token ?? ''),
        email: c.email ?? '',
        delivery_country: c.shippingAddress?.countryCode ?? 'IL',
        estimated_delivery_date: deliveryDate,
        opt_in_style: 'CENTER_DIALOG',
      });
    });
  };

  document.head.appendChild(s);
});
```

**התג (badge)** נפרד, ואינו חובה לאיסוף הנתונים — הוא רק מציג את הדירוג.
אם רוצים אותו, הוא נכנס לתבנית ולא לפיקסל, ב-`theme.liquid` לפני `</body>`:

```html
<!-- Google Customer Reviews badge -->
<script src="https://apis.google.com/js/platform.js?onload=renderBadge" async defer></script>
<script>
  function renderBadge() {
    var el = document.createElement('div');
    el.id = 'badge-container';
    document.body.appendChild(el);
    window.gapi.load('ratingbadge', function () {
      window.gapi.ratingbadge.render(el, { merchant_id: 5328155131, position: 'BOTTOM_LEFT' });
    });
  }
</script>
```

**לבדוק אחרי ההתקנה:** לבצע הזמנת בדיקה ולראות שהדיאלוג מופיע בעמוד התודה.
MC מציג נתונים תוך כמה ימים, לא מיד.

## 5. מלאי מקומי — דורש פיד, לא הגדרה

2,057 מוצרים מסומנים כחסרי נתוני מלאי מקומי. באפליקציית Google & YouTube
ב-Shopify אין אפשרות סנכרון מלאי מקומי, ולכן זה לא ניתן להפעלה משם.

הדרכים הקיימות:
- אפליקציה של צד שלישי לפיד מלאי מקומי.
- פיד ידני ב-MC: `Products → Feeds → Local product inventory`, קובץ עם
  `store_code`, `id`, `price`, `availability` לכל מוצר וחנות.

זה משפיע **רק על הצגה בחנות הפיזית** ולא על הליסטינגים באונליין, ולכן זה
הפריט בעל העדיפות הנמוכה ביותר בדוח.

## 6. מה שחסום ולא ניתן לתיקון כרגע

98 מוצרים ב-0 ₪, 11 בלי תמונה, ו-196 בלי תיאור אמיתי. כל השלושה תלויים
בעמודי ספק, וכל הספקים — כולם על פלטפורמת Konimbo — חוסמים כרגע את הכתובת
הזאת. החתימה: HTTP 200 עם גוף של כ-1,622 בתים, בלי JSON-LD.

הסקריפטים כתובים ומזהים את החסימה במקום לפרש אותה כמוצר חסר:
`scripts/fill-descriptions.js`, `scripts/fill-gaps-from-catalogues.js`,
`scripts/apply-price-list.js`. מריצים אותם כשהחסימה משתחררת.

**שני מוצרים שהיו ניתנים לרכישה ב-0 ₪ הוצאו לטיוטה** — שואב אבק 80 ליטר
ושקע טלפון כפול. זה הפיך ברגע שיש להם מחיר.
