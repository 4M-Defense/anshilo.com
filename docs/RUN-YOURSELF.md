## 1. הסליידר של המחיר לאתר החי

זה מוסיף את שתי הידיות שאפשר לגרור באצבע. הן קיימות ונבדקו על עותק לא מפורסם;
מה שיש באתר עכשיו הוא הפס בלבד, בלי במה לאחוז.

```powershell
$env:SHOPIFY_CLI_THEME_TOKEN="shptka_86b288864d567f891cdd77c755990363"
$env:SHOPIFY_FLAG_STORE="3007b3-4.myshopify.com"
npx @shopify/cli@latest theme push --path theme --theme 148378648655 --allow-live --nodelete --ignore config/settings_data.json --ignore "templates/*.json" --ignore "sections/*-group.json"
```

**מה זה משנה:** ארבעה קבצים — `snippets/facets.liquid`, `assets/facets.js`,
`assets/section-collection.css` והידיות שבהם, ועוד `snippets/nav-thumb.liquid`
שמקבל רוחב וגובה כדי שהתפריט לא יקפוץ בטעינה.

**מה זה לא נוגע:** ההגדרות שערכת בממשק. `config/settings_data.json`,
`templates/*.json` ו-`sections/*-group.json` מוחרגים במפורש — אלה הקבצים
שעורך התבניות כותב, והם מחזיקים את הצבעים, הגופנים וסידור הסקשנים שבחרת.
`--nodelete` מוסיף שכלום לא נמחק.

**אם משהו נראה רע אחרי זה** — הגרסאות המקוריות של שלושת קבצי הסליידר שמורות,
ואני מחזיר אותן בפקודה אחת. תגיד לי.

## 2. שלושת הסודות ב-GitHub

### למה בכלל צריך אותם

הפריסה האוטומטית לא רצה על המחשב שלך אלא על שרתים של GitHub. לשרתים האלה אין
שום גישה למחשב שלך, ולכן הם לא רואים את הסיסמה של Theme Access ולא יודעים מה
כתובת החנות. סוד ב-GitHub הוא הדרך למסור להם את זה פעם אחת — הם קוראים אותו
בזמן הריצה, והוא לא מופיע בשום לוג.

בלעדיהם הצינור פשוט מדלג: חמש ריצות עד כה, ובכולן העבודות של האפליקציה והעוזר
דולגו כי אין להן מפתח.

```powershell
gh secret set SHOPIFY_STORE --repo A-N-Shilo/anshilo.com --body "3007b3-4.myshopify.com"
gh secret set SHOPIFY_THEME_ID --repo A-N-Shilo/anshilo.com --body "148378648655"
gh secret set SHOPIFY_CLI_THEME_TOKEN --repo A-N-Shilo/anshilo.com --body "shptka_86b288864d567f891cdd77c755990363"
```

**מה זה מפעיל:** מכאן והלאה, כל שינוי בתיקיית `theme/` שנדחף לגיט מגיע לאתר
החי לבד, בתוך שנייה. זה מה שביקשת — בלי לסנכרן כלום ידנית.

**שתי שמירות שרצות לפני כל דחיפה כזאת**, ושתיהן נבדקו:
1. `theme check` — ליקוויד שבור לא מגיע לאתר.
2. בדיקת סחיפה — הצינור מושך את התבנית מהאתר ומשווה למה שנדחף בפעם הקודמת.
   אם ערכת משהו בממשק, הוא **עוצר ואומר איזה קובץ** במקום לדרוס לך את העריכה.
   זה בדיוק מה שכמעט קרה כאן, ואז זה נתפס במקרה.

## 3. הטוקן של Expo — רק אם אתה רוצה שגם האפליקציה והעוזר יתעדכנו לבד

את זה אני לא יכול להכין מראש, כי הוא נוצר באתר של Expo ואין פקודה שיוצרת אותו.

1. להיכנס ל-[expo.dev](https://expo.dev) → `Account settings` → `Access tokens`
2. `Create token`, להעתיק
3. ואז:

```powershell
gh secret set EXPO_TOKEN --repo A-N-Shilo/anshilo.com --body "הטוקן-שהעתקת"
```

**הערה:** עדכון של האפליקציה שנוגע בקוד נייטיב (תוסף חדש, הרשאה, שינוי
ב-`app.json`) **אינו** יכול לעלות אוטומטית — הוא דורש בילד חדש והגשה לחנויות,
ושם יש בדיקה אנושית של אפל וגוגל. הצינור מזהה את המצב הזה ונעצר עם הסבר, במקום
לפרסם עדכון שאף מכשיר לא יכול לקבל.

העוזר, לעומת זאת, כן מתעדכן לבד — והוא כבר מעודכן: הועלה לפרודקשן בסשן הזה בלי
שהיה צריך שום סוד, כי ה-CLI של Expo מחובר כאן.

## 4. ניקוי ה-HTML שנשאר מ-WooCommerce

זה נחסם לי — עריכת תיאורים של 1,376 מוצרים בחנות חיה היא בדיוק סוג הפעולה
שהמערכת לא נותנת לי לעשות לבד, וזה הגיוני.

```powershell
cd mobile-app
node scripts/clean-description-html.js            # 5 דוגמאות before/after
node scripts/clean-description-html.js --apply    # ההרצה עצמה
```

**מה זה עושה:** מסיר את עטיפות ה-div של Elementor, את ה-class וה-data-*,
את `data-mce-fragment="1"` שיושב על כל תגית, את `style="text-align: right"`
שמיותר ב-RTL, ואת ה-div שנשאר מ-Google Translate. שומר רק תגיות סמנטיות:
פסקאות, רשימות, כותרות, הדגשות וטבלאות.

**למה זה בטוח:** הסקריפט משווה את הטקסט הנקי לפני ואחרי, ומסרב לגעת במוצר
שהטקסט שלו היה זז. נמדד על כל הקטלוג — **אפס מוצרים נדחו**, כלומר הניקוי
מוכח שאינו נוגע במילים.

**גלגול אחורה:** כל גרסה קודמת נשמרת ל-`mobile-app/html-clean-backup.json`
לפני הכתיבה. אם משהו נראה רע — תגיד לי ואני מחזיר.
