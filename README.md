## 🎨 ערכת העיצוב — Shilo Pro

ת'ים Online Store 2.0 שנבנה מאפס במיוחד לחנות, עם עיצוב תעשייתי-פרימיום:

- **RTL מלא** — עברית כשפת ברירת מחדל, כולל תרגום מלא לאנגלית
- **עיצוב ייחודי** — פלטת צבעים של "מקצוענים": כתום בטיחות על כהה-פחם, מוטיב פסי אזהרה עדין
- **חיפוש חכם** — חיפוש מיידי תוך כדי הקלדה עם תוצאות חיות (מוצרים, קטגוריות, עמודים)
- **עגלה צדדית (Drawer)** — הוספה לעגלה בלי לעזוב את העמוד, כולל פס התקדמות למשלוח חינם
- **סינון ומיון מתקדמים** — פילטרים לפי מותג, מחיר וזמינות בלי טעינת עמוד
- **עמוד מוצר משכנע** — גלריה, בחירת וריאנטים, חיווי מלאי, אזורי אמון, מוצרים קשורים
- **מהיר ונגיש** — תמונות lazy, אנימציות עדינות, ניווט מקלדת, ARIA מלא
- **הכל ניתן לעריכה** — צבעים, גופנים, סקשנים — דרך עורך הת'ים של שופיפיי, בלי קוד

📖 **[מדריך התקנת הת'ים ←](docs/INSTALL-THEME.md)**

## 📱 אפליקציית המובייל

אפליקציה native ל-iOS ולאנדרואיד (Expo / React Native) שמושכת את המוצרים, הקטגוריות והמלאי ישירות מהחנות דרך Shopify Storefront API:

- **קטלוג מלא** — דף בית עם קטגוריות ומוצרים מומלצים, עמודי קטגוריה עם מיון וטעינה אינסופית
- **חיפוש מוצרים** מהיר
- **עגלת קניות אמיתית** — מסונכרנת עם שופיפיי, נשמרת בין הפעלות
- **תשלום מאובטח** — ה-checkout המלא של שופיפיי (כולל כל אמצעי התשלום שמוגדרים בחנות)
- **מועדפים**, יצירת קשר בלחיצה (טלפון/וואטסאפ), עברית מלאה RTL

## התחלה מהירה

### הת'ים (5 דקות)

```bash
cd theme && zip -r ../shilo-pro-theme.zip . -x "SPEC.md"
```

ואז בניהול החנות: **Online Store → Themes → Add theme → Upload zip file**, בודקים בתצוגה מקדימה ולוחצים **Publish**.

### האפליקציה (10 דקות)

1. יוצרים טוקן Storefront API בניהול החנות (הוראות מלאות ב-[docs/INSTALL-APP.md](docs/INSTALL-APP.md))
2. מדביקים אותו ב-`mobile-app/src/config.ts`
3. מריצים:

```bash
cd mobile-app
npm install
npx expo start
```

וסורקים את ה-QR עם אפליקציית **Expo Go** בטלפון.
