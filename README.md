## מה השתנה בעיצוב, ולמה

הגרסה הקודמת של הת'ים הייתה בנויה טוב מבחינת קוד, אבל שני דברים הרסו אותה:

1. **דף הבית היה ריק מתוכן.** קובץ התבנית הכיל את כל הסקשנים בלי אף הגדרה — בלי
   קטגוריות, בלי תמונות, בלי כותרות. התוצאה נראתה כמו רשימת מלבנים אפורים.
2. **הפרטים היו שגויים** — טלפון פיקטיבי, ובכתובת נרשם "קרית אתא" במקום קרית ענבים.

מעבר לזה, שפת העיצוב עצמה (כתום על פחם עם פסי אזהרה מלוכסנים) נלחמה בקטלוג של
1,918 מוצרים במקום לעזור לסרוק אותו.

### הכיוון החדש — "בהירות"

| | קודם | עכשיו |
|---|---|---|
| צבע מותג | כתום על רקע פחם | אדום שילו `#D81E29`, **רק** לכפתורים ולמחירים |
| מבנה | בלוקים כהים גדולים | כחול־כהה להדר, לפוטר ולכותרות; קנבס בהיר לשאר |
| מוטיב | פסי אזהרה מלוכסנים | רשת שרטוט עדינה |
| גופנים | בוררי הגופנים של שופיפיי | Heebo + Assistant, **מאוחסנים בתוך התמה** |
| כרטיסים | שטוחים וצפופים | לבנים, מסגרת דקה, פינות רכות, ארבע דרגות צל |

**על הגופנים:** ספריית הגופנים של שופיפיי כוללת רק אותיות לטיניות — **כל** גופן
שם מרנדר עברית בגופן ברירת המחדל של המחשב. לכן Assistant ו-Heebo מאוחסנים
ישירות בתוך התמה כקבצי WOFF2 משתנים. מבקר בעברית מוריד כ-19KB ומקבל את כל טווח
המשקלים.

הכללים המחייבים מרוכזים ב-[`theme/DESIGN-SYSTEM.md`](theme/DESIGN-SYSTEM.md).

התפריט הקיים לא היה מאוזן: רק ל"כלי עבודה" היה עץ אמיתי, ולשמונה הפריטים
האחרים לא היו תתי-קטגוריות בכלל. נבנה תפריט חדש בשם **`shilo-2026-main`** —
12 מחלקות, 127 פריטים בשלוש רמות, 119 קטגוריות, כולן מאומתות כמפורסמות ועם
מוצרים. **התפריט הקיים לא נגעו בו.**

## התחלה מהירה

### הת'ים

הוא **כבר פרוס** — פשוט פתחו את הקישור למעלה. להוראות פרסום, עריכת צבעים
והחלפת תמונות: [`docs/INSTALL-THEME.md`](docs/INSTALL-THEME.md).

### האפליקציה

```bash
cd mobile-app
npm install
# מדביקים טוקן Storefront API ב-src/config.ts
npx expo start
```

וסורקים את ה-QR עם **Expo Go**. הוראות מלאות, כולל יצירת הטוקן והעלאה לחנויות
האפליקציות: [`docs/INSTALL-APP.md`](docs/INSTALL-APP.md).

## בדיקות

```bash
python3 theme/tools/validate.py          # בדיקות סטטיות + כללי מערכת העיצוב
cd mobile-app && npx tsc --noEmit        # בדיקת טיפוסים לאפליקציה
```

מצב נוכחי: הוואלידטור המקומי — 0 שגיאות. `theme-check` הרשמי של שופיפיי — 0 שגיאות.
בדיקת הטיפוסים של האפליקציה — 0 שגיאות.

יש גם [`theme/tools/shoot.mjs`](theme/tools/shoot.mjs) לצילום מסך ובדיקה
אוטומטית של העמודים בשתי רזולוציות — צריך להריץ אותו מרשת שיכולה להגיע
ל-anshilo.com.
