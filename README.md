# shopify-live — הענף שמחובר לשופיפיי

הענף הזה מחובר (או מיועד להתחבר) לערכת העיצוב בחנות דרך האינטגרציה הרשמית
Shopify ↔ GitHub. **כל push לענף הזה מתעדכן מיד בערכה המחוברת**, ושינויים
שנעשים בעורך הת'ים של שופיפיי חוזרים לכאן כקומיטים אוטומטיים.

- קוד המקור המלא (כולל האפליקציה, המדריכים וכלי הבדיקה) חי בענף
  `claude/shopify-store-modern-design-746p2i`, בתיקיית `theme/`.
- לסנכרן שינויי קוד לכאן: מריצים מהענף הראשי
  `bash theme/tools/sync-shopify-live.sh` (או ידנית: להעתיק את תוכן `theme/`
  לשורש הענף הזה, בלי `tools/`, `SPEC.md`, `DESIGN-SYSTEM.md`).
- לפני כל סנכרון: `git pull` — ייתכן ששופיפיי הוסיפה כאן קומיטים מהעורך.
