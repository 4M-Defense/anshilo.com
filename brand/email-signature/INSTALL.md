# התקנת החתימה

הקובץ `signature-he.html` הוא HTML מוכן. **לא פותחים אותו בעורך של תוכנת המייל
ומעצבים מחדש** - מדביקים אותו כמו שהוא, אחרת העורך יהרוס את המבנה.

## הדרך שעובדת בכל הלקוחות: להעתיק *מרונדר*

1. פותחים את `signature-he.html` בכרום (לחיצה כפולה על הקובץ).
2. `Ctrl+A` ואז `Ctrl+C` - מסמנים ומעתיקים את מה שנראה, לא את הקוד.
3. מדביקים בשדה החתימה של תוכנת המייל.

זה עובד כי הדפדפן מעביר את העיצוב ה-inline יחד עם הטקסט בלוח.

## Gmail

הגדרות → כללי → חתימה → צור חדשה → מדביקים (`Ctrl+V`).
בסוף העמוד: **שמור שינויים**.

בבורר החתימות למטה כדאי לקבוע אותה גם ל"שימוש בהודעות חדשות" וגם
ל"בתגובות/העברות".

> ג'ימייל חותך חתימות ארוכות מאוד עם `[...]`. זו קצרה, זה לא יקרה.

## Outlook (Windows / Microsoft 365)

קובץ → אפשרויות → דואר → חתימות → חדשה → מדביקים → אישור.

> Outlook מרנדר עם מנוע Word. בגלל זה החתימה בנויה טבלאות ובלי פינות מעוגלות
> ובלי צללים - כדי שהיא תיראה זהה שם. אם משהו נראה זז, זה כמעט תמיד סימן
> שהעורך ניסה "לתקן" את ה-HTML; מדביקים מחדש בלי לגעת.

## Outlook Web / Apple Mail / iOS

- **Outlook Web:** Settings → Mail → Compose and reply → מדביקים.
- **Apple Mail:** Mail → Settings → Signatures → יוצרים חדשה → מדביקים →
  **מבטלים את הסימון** "Always match my default message font", אחרת Mail ידרוס
  את הגופנים.
- **iOS Mail:** לא תומך בחתימה עשירה. שם משתמשים ב-`signature.txt`.

## הלוגו

ה-`src` בקובץ מצביע לכתובת הציבורית של הלוגו ב-CDN של החנות:

```
https://cdn.shopify.com/s/files/1/0581/1024/6991/files/final-logo-for-the-website.png
```

זה מכוון. **חייבים כתובת ציבורית** - אם משתמשים בקובץ מהמחשב, הנמען יראה ריבוע
שבור, כי הקובץ קיים רק אצלכם. אל תמחקו את הקובץ הזה מספריית הקבצים של שופיפיי:
כל חתימה שנשלחה בעבר תפסיק להציג לוגו.

חלק מלקוחות המייל חוסמים תמונות כברירת מחדל, ולכן כל פרט חשוב בחתימה מופיע
כטקסט אמיתי ולא בתוך התמונה. גם עם תמונות חסומות החתימה שלמה וקריאה, עם
`א.נ. שילו בע"מ` כטקסט חלופי במקום הלוגו.

## אנשים נוספים בחברה

לכל עובד נוסף: להעתיק את `signature-he.html`, לשנות **שתי שורות בלבד** - השם
והתפקיד - ואת הנייד. כל השאר זהה לכולם, וזה בכוונה: אחידות בחתימות היא חלק
מהמותג בדיוק כמו הלוגו.

את התפקיד כותבים דו-לשוני באותו מבנה: `מנהל החנות · Store Manager`.
