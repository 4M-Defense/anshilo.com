# קבצי הגופנים

שני גופני המותג, בדיוק אותם קבצים שרצים באתר (`theme/assets/`). הם כאן כדי
שהתיקייה תהיה שלמה: מי שמקבל אותה מקבל גם את הגופנים, בלי לחפש.

| קובץ | גופן | טווח תווים |
|---|---|---|
| `heebo-var-hebrew.woff2` | Heebo | עברית |
| `heebo-var-latin.woff2` | Heebo | לטינית בסיסית |
| `heebo-var-latin-ext.woff2` | Heebo | לטינית מורחבת |
| `assistant-var-hebrew.woff2` | Assistant | עברית |
| `assistant-var-latin.woff2` | Assistant | לטינית בסיסית |
| `assistant-var-latin-ext.woff2` | Assistant | לטינית מורחבת |

**גופנים משתנים (variable):** כל קובץ מכיל את כל טווח המשקלים - Heebo `300-900`,
Assistant `300-800`. אין קובץ נפרד לכל משקל.

**הפיצול לשלושה קבצים** הוא אופטימיזציה לאתר: הדפדפן מוריד רק את הטווח שמופיע
בעמוד. בעבודה מקומית - עיצוב, דפוס, מסמך - **פשוט מתקינים את כל השישה** ומקבלים
גופן אחד שלם בכל התוכנות.

## התקנה

- **Windows:** לסמן את כל הקבצים → קליק ימני → **התקן**.
- **macOS:** לסמן הכול → פתיחה עם **Font Book** → **Install**.

WOFF2 הוא פורמט ווב. הוא נתמך בהתקנה מקומית במערכות עדכניות, אבל **אם תוכנה
כלשהי לא מזהה אותו** - להוריד את גרסת ה-TTF מ-Google Fonts. אותם גופנים בדיוק:

```
https://fonts.google.com/specimen/Heebo
https://fonts.google.com/specimen/Assistant
```

## רישיון

שני הגופנים מופצים תחת **SIL Open Font License 1.1**. משמעות מעשית:

- מותר להשתמש מסחרית, בלי תשלום ובלי הגבלה על מספר משתמשים.
- מותר להעביר את הקבצים למעצב חוץ, לבית דפוס או לספק - כולל בתוך התיקייה הזאת.
- מותר להטמיע ב-PDF, וזה מה שנעשה ב-`../../brand-guide.pdf`.
- **אסור למכור את הגופנים בעצמם**, ואסור לשנות אותם ולהפיץ תחת אותו שם.

נוסח הרישיון המלא מגיע עם ההורדה מ-Google Fonts (קובץ `OFL.txt`). הוא לא צורף
כאן כדי לא לשמור עותק שעלול להיות לא מדויק - **מי שצריך את הנוסח המחייב, לוקח
אותו משם**.
