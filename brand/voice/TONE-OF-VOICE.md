# שפה וניסוח

הקהל הוא קבלנים, נגרים, חשמלאים ואינסטלטורים - ובעלי בתים שיודעים מה הם מחפשים.
**הם מגיעים עם מקט או עם שם מוצר, לא עם השראה.** כל כלל כאן נגזר מהמשפט הזה.

---

## 1. שלוש תכונות של הקול

### מקצועי, לא רשמי

מדברים כמו איש מקצוע לאיש מקצוע. בגובה העיניים, בלי התיילדות ובלי לשון גבוהה.

```
✓  הצוות מלווה אתכם משלב התכנון ועד ההעמסה על הרכב.
✗  צוות המומחים שלנו ישמח להעניק לך ליווי מקצועי לאורך כל הדרך.
✗  שלום חבר! מחפש כלי עבודה? באת למקום הנכון 😊
```

### מדויק, לא מנופח

מספר עדיף על תואר. **"1,900 מוצרים במלאי"** אומר יותר מ"מבחר עצום", והוא גם ניתן
לבדיקה. ותק נמדד בשנים, לא ב"ניסיון עשיר".

```
✓  354 מוצרי מקיטה
✓  מאז 1990 · קיבוץ קרית ענבים
✗  מבחר בלתי נתפס של הכלים הטובים בעולם
```

### בטוח, לא מתנשא

הביטחון בא מהעובדות. אין צורך להוסיף לו סימני קריאה.

```
✓  אחריות מלאה מיבואן רשמי
✗  אנחנו הטובים בארץ!!!
```

## 2. ניסוח - כללי עבודה

**לקוח בגוף שני רבים.** "אתם", "תמצאו", "מחכה לכם". זו צורת הפנייה הנייטרלית
בעברית - היא מתאימה גם ליחיד וגם לרבים ואינה מחייבת לנחש מגדר.
**לא "לקוח יקר"** ולא "משתמש".

**חברה בגוף ראשון רבים.** "אנחנו מחזיקים", "הצוות שלנו". לא "החברה מעמידה
לרשותכם".

**פעיל, לא סביל.** "אנחנו חותכים לפי מידה", לא "החיתוך מבוצע לפי מידה".

**קצר.** משפט אחד = רעיון אחד. אם צריך לקרוא פעמיים - לפצל.

**כפתור מתחיל בפועל ואומר מה יקרה.**

```
✓  הוסיפו לסל     ✓  לכל מוצרי מקיטה     ✓  בקשו הצעת מחיר
✗  שלח            ✗  לחץ כאן             ✗  המשך
```

**שגיאה אומרת מה לעשות, לא מי טעה.**

```
✓  המוצר אזל מהמלאי. אפשר להשאיר טלפון ונעדכן כשיחזור.
✗  שגיאה: המוצר אינו זמין.
```

## 3. מקף - הכלל הנוקשה ביותר במסמך

**מקף רגיל `-` בלבד. תמיד. בכל מקום.**

| |
|---|
| ✗ `—` מקף אם (em dash) |
| ✗ `–` מקף אן (en dash) |
| ✗ `־` מקף עברי (maqaf) |
| ✓ `-` מקף-מינוס רגיל |

זה לא עניין של טעם. בהקשר RTL המקפים הטיפוגרפיים מתנהגים אחרת מהמקף הרגיל: הם
לא נשארים במקום שבו נכתבו, ומספר טלפון או טווח שעות יוצא הפוך. הם גם מרנדרים
שונה בגופנים שונים ובלקוחות מייל, ולפעמים לא מרנדרים בכלל.

הכלל הזה נאכף על **כל** הטקסט של האתר, וכן על החתימות, על המסמכים ועל כל תוכן
חדש. אם מדביקים טקסט מוורד או מ-Google Docs - **לבדוק**: שני המעבדים מחליפים
מקפים אוטומטית.

## 4. עברית - מלכודות שחוזרות

**אין CAPS על עברית.** לעברית אין אותיות גדולות. `text-transform: uppercase` על
מילה עברית לא עושה כלום, אבל **כן** משפיע על מותג לטיני באותו משפט: `Makita`
הופך ל-`MAKITA` וצועק.

**מספרים, טלפונים, מחירים ומקטים - עטופים ב-`dir="ltr"` עם `unicode-bidi:
isolate`.** בלי זה הספרות מסתדרות מחדש והטלפון יוצא הפוך. הפירוט
ב-`../type/TYPOGRAPHY.md` סעיף 4.

**שמות מותגים בכתיב כפול, בסדר קבוע: עברית ואז לטינית.**

```
✓  מקיטה MAKITA     ✓  מילווקי MILWAUKEE     ✓  סימנס SIEMENS
```

זה מכוון: אנשים מחפשים בשתי הצורות, ולכן שתיהן צריכות להופיע בטקסט.

**גרשיים רגילים.** `בע"מ` עם `"`, לא `״` ולא `“ ”`. `א'-ה'` עם גרש רגיל `'`.
זה גם מה שמאפשר לחיפוש והחלפה לעבוד על כל הקבצים.

**מיקוד וספרות** - תמיד בספרות, לא במילים.

## 5. פורמטים קבועים

| | הפורמט | דוגמה |
|---|---|---|
| טלפון | קווקוו בקבוצות | `02-534-3422` |
| נייד | קווקוו בקבוצות | `054-466-5919` |
| בינלאומי | `+972` בלי 0 מוביל | `+972-2-534-3422` |
| שעות | `א'-ה' 07:00-17:00` | לא "7 בבוקר" |
| מחיר | `₪` לפני הספרות | `₪399` |
| כמות | פסיק לאלפים | `1,918 מוצרים` |
| ותק | **מוצמד לשנה** | `מאז 1990` |

**על הותק:** באתר מופיעים גם `מאז 1990` וגם `מעל 30 שנה`. שניהם נכונים, אבל
`30+` מתיישן בשקט - בעוד ארבע שנים הוא יהיה לא מדויק ואף אחד לא ישים לב.
**עדיף להצמיד לשנה** ולתת לקורא לחשב. אם כן משתמשים ב"מעל 30 שנה", זה תמיד לצד
`1990` באותו אזור בעמוד.

## 6. מה לא כותבים

| ✗ | למה |
|---|---|
| "הכי זול בארץ" בלי גיבוי | טענת השוואה שאי אפשר להוכיח היא חשיפה משפטית |
| "מהיר!!!", "מדהים!!!" | סימני קריאה כפולים |
| אימוג'י בטקסט מוצר או מחלקה | מותר בשיווק לרשתות, לא בקטלוג |
| ז'רגון פנימי - "SKU", "פריט לוגיסטי" | הלקוח אומר "מקט" |
| "עמוד זה" / "לחץ כאן" | קישור אומר לאן הוא מוביל |
| "מלאי מוגבל!" כשזה לא נכון | דחיפות שקרית נשרפת בפעם השלישית |
| מילה באנגלית שיש לה מקבילה עברית | `Sale` → `מבצע`, `New` → `חדש` |

## 7. סוגי טקסט - אורך ומה חייב להופיע

**כותרת סקשן.** עד 8 מילים. מה יש שם, לא מטאפורה.
`קונים לפי מחלקה` · `המותגים שאנחנו מייצגים` · `הנמכרים ביותר`

**כותרת מחלקה או קמפיין.** מותר להוסיף את הבידול אחרי מקף:
`עץ, לוחות וקורות - בחיתוך לפי מידה`

**שם מוצר.** יצרן, דגם, מקט, מידה. **אין תוארי שבח בשם מוצר** - הם מפריעים
לחיפוש ולהשוואה.

**תיאור מוצר.** 2-4 שורות: מה זה, למה זה טוב לעבודה הזאת, מה מגיע בקופסה.

**הבטחת שירות.** ארבע מילים לכל היותר, ובלי סימן קריאה:
`אחריות מלאה מיבואן רשמי` · `ייעוץ מקצועי חינם` · `איסוף עצמי מהחנות`

**מייל שיווקי - שורת נושא.** עד 45 תווים, בלי אימוג'י, בלי CAPS.

## 8. בדיקה לפני פרסום, שבע שאלות

1. יש `—` `–` או `־` בטקסט? → החלפה ל-`-`.
2. כל מספר, טלפון ומחיר עטוף ב-`dir="ltr"` עם `isolate`?
3. יש מילה באנגלית שיש לה מקבילה עברית?
4. יש טענה שאי אפשר להוכיח?
5. כל כפתור מתחיל בפועל ואומר מה יקרה?
6. אפשר להוריד מילים בלי לאבד מידע? → להוריד.
7. מותג לטיני שעלול לעבור `uppercase`?

השאלה הראשונה היא זו שנכשלת הכי הרבה.
